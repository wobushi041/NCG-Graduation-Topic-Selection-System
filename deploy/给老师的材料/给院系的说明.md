# 毕业设计选题系统 · 名单收集说明

系统地址：https://topic.lqlab.cn

请协助收集以下 **3 份名单**，填在随附的 CSV 模板中发回即可。系部统一为「工学院」，模板里不用填。

## 一、需要交回的 3 份名单

| 模板文件 | 用途 | 填表人 |
| --- | --- | --- |
| 教师名单.csv | 开通指导老师账号 | 院系教务 |
| 学生名单.csv | 开通学生账号 | 院系教务 |
| 专业负责人名单.csv | 单独开通专业负责人账号（负责审核题目） | 院系教务 |

## 二、填表注意（重要）

1. 专业只能填以下 8 个之一，必须逐字一致：
   计算机科学与技术 / 软件工程 / 数据科学与大数据技术 / 数据科学与大数据技术（中外） / 智能科学与技术 / 电气工程及其自动化 / 电子信息科学与技术 / 通信工程
2. 学号、工号：请先把该列设为「文本」再填写，避免 Excel 把长数字变成科学计数法或丢掉前导零。
3. 不要改动表头、列顺序，不要新增或删除列。
4. 文件请用「CSV UTF-8」格式保存，或直接发回 Excel 原文件。
5. 初始密码由技术人员统一生成，不需要填写。
6. 专业负责人名单按「每个专业 1 位」填写，共 8 位。

## 三、各模板字段与示例

### 教师名单.csv

表头：`工号,姓名,专业,最大出题数量`

示例：

```csv
2021001,张老师,计算机科学与技术,8
2021002,李老师,软件工程,6
```

「最大出题数量」填 0–20 的整数，表示这位老师最多能发布几道题。

### 学生名单.csv

表头：`学号,姓名,专业`

示例：

```csv
20220101,张三,计算机科学与技术
20220102,李四,软件工程
```

### 专业负责人名单.csv

表头：`工号,姓名,专业`

示例：

```csv
2021003,王老师,计算机科学与技术
2021004,李老师,软件工程
```

专业负责人负责审核本专业的题目，**每个专业 1 位**；账号由后台单独开通，不能由教师账号兼任。

## 四、需要院系一并确认的事项

1. 每位教师的出题上限（统一标准，或逐人填在教师名单里）。
2. 专业负责人人选（每个专业 1 位，共 8 位）。
3. 选题时间：预选开始/结束时间、正式确认开始/结束时间。
4. 选题模式：学生选老师 / 老师选学生。
5. 是否启用「退选加锁」及加锁时间（加锁后学生不能退选）。

选题组已配置好：计算机科学与技术 + 软件工程 = **计算机类**；数据科学与大数据技术 + 智能科学与技术 + 数据科学与大数据技术（中外） = **数据智能类**；电气工程及其自动化 + 电子信息科学与技术 + 通信工程 = **电子电气类**。
